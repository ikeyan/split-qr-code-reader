# WebGPUによる位置検出と曲面推定

読み取り方法が「自動」「曲面補正」のとき、WebGPUが利用可能なら小型NNによる経路を先に試す。「曲面推定 NN」と「曲面推定 従来」を、通常画面とカメラ表示中の選択欄で切り替えられる。従来方式でもGPUが利用可能ならNNによるマーカーの評価・局所位置の推定を使用し、曲面の推定を既存の幾何モデルで行う。

NNは各マーカーの周辺を個別に処理する。全画像にマーカーが3個しかないとは仮定しない。黒い連結領域と既存検出器の候補を評価し、複数の3個組からQRごとの格子を作る。偽の組み合わせや本文の模様を誤採択しないよう、最終結果はZXingの有効な復号結果から取得する。Structured Append情報も復号結果を維持する。複数のQRの結果を位置と内容で統合する。

モデルは2種類ある。

- マーカーモデルは32×32の局所画像から、位置検出パターンの確信度、中心、縦横の局所的な向きと間隔を推定する。全結合層の寸法は1024→128→64→7。
- 曲面モデルは3つのマーカーの局所的な向き・間隔を、それらの中心が作る座標系で表した12個の値とQRサイズを入力とし、9×9格子の変位を出力する。寸法は13→128→128→162。固定模様を使う局所的な調整とアライメントパターンによる補間を加える。圧縮されたセルは複数点を標本化する。

合計179,113パラメータ。配布する `vendor/qr-networks.json` はlittle-endian float32をbase64化した約0.96 MBのファイル。モデルはページと同じ配信元から取得し、学習済み層の計算はWebGPUのcompute shaderで行う。ページとWorkerの両方でアダプター、モデル読込、シェーダー、読戻しを確認する。GPUが利用できない、拒否された、モデルをロードできない、デバイスを失った場合にはNNを停止して既存処理を使い、ページ下部のコミットIDの後ろに `No GPU` を表示する。NNで復号できなかった画像にも既存処理を試す。

## 学習の再現

Python 3.12、numpy 2.3.5、PyTorch 2.15.0+cpuを使用した。CPUで学習でき、PyTorchは開発用依存だけである。

```sh
python -m venv /tmp/qr-nn-venv
/tmp/qr-nn-venv/bin/pip install numpy==2.3.5
/tmp/qr-nn-venv/bin/pip install torch==2.15.0+cpu --index-url https://download.pytorch.org/whl/cpu
/tmp/qr-nn-venv/bin/python scripts/nn/train.py --output /tmp/qr-nn-trained --deploy vendor/qr-networks.json
```

学習スクリプトはそれぞれ65,536例と別シードの検証用4,096例を生成する。マーカーはQR仕様の固定模様に、向き・縦横比・ずれ・照明勾配・ノイズを加え、ランダムなデータ模様やアライメントパターンを負例にする。曲面は透視投影した円筒の幾何情報から生成し、曲げの方向・強さ・中心のずれ・視点・QRサイズを変える。折り返す格子を除く。学習回数は曲面6,000、マーカー8,000更新、バッチ1,024。乱数シード、モデルの寸法、損失関数をスクリプトに記録している。共有された写真・録画・抽出した本文を学習には使わない。

## 検証

```sh
deno task build
deno task check
deno task test
CHROME_BIN=/usr/bin/chromium deno task test:gpu
```

`neural_test.ts` は、学習器と別実装の3D描画との格子座標の誤差、3つのQR・9つのマーカーからの本文の完全一致、GPU利用不可時の初期化を検査する。モデルの重みをCPUで照合する関数はテスト用ファイルに置く。アプリのNN推論はWebGPU上で実行する。

`test:gpu` はChromiumのWebGPUで2モデルの数値をCPUの照合結果と比較し、アプリのカメラ入力から本文表示までを確認する。曲面推定の切り替え、アダプター欠如・拒否、デバイス喪失時のフォールバックと `No GPU` 表示も検査する。この環境ではSwiftShaderを使用するため、端末GPUの処理時間の評価には実機が必要となる。

このモデルは比較・改善を続ける初期実装であり、30〜40度の斜め撮影で曲がったQRを安定して復号する目標にはまだ達していない。今回の開発用の斜め撮影8例ずつでは、NN経路単独の完全復号は30度で3/8、40度で0/8だった。既存の幾何モデルへのフォールバックを維持している。正しい格子が与えられた場合と比べて、特に圧縮されたマーカーの検出・局所的な向きの推定に改善が必要である。
